# 统一术语

[英文版本](TERMS.md)

状态：`pulse-terms.v1` 当前版本。

稳定对象名与协议名在翻译会改变身份时保留英文；普通界面叙述仍应本地化。是否保留
专有名词取决于语义与一致性，不取决于字符种类。

| 统一术语 | 朴素含义 | 不等同于 |
|---|---|---|
| PulseWorld | 多个 Engram 共享的一个持久世界与控制面 | 聊天窗口或单个任务 |
| Engram | PulseWorld 中的一个持久认知参与者 | 浏览器标签页、进程或模型上下文 |
| EngramLineage | 跨换代延续的身份引用 | 当前进程 |
| EngramGeneration | lineage 中的一代有限存在 | 整个 lineage |
| PiSession | 某一代实际使用的 provider/模型会话 | SQLite 世界状态 |
| TaskOffer | 等待主体决定的拟议任务条款 | 已经接受的工作 |
| TaskRelationship | 接受后由主体掌握的参与状态 | 永久权限 |
| TaskFront | 一项任务的持久用户入口 | 新主体 |
| Life Center | 任务之外的持久活动表面 | 强制任务队列 |
| RoleLease | 有范围、会到期、可撤销的授权 | 永久管理员身份 |
| Purpose | 可不建立、也可修订的主体持有陈述 | 系统权限或强制目标 |
| WorldTick | 对时钟、队列与资源状态的低成本推进 | 思考或模型调用 |
| Pulse | 一次改变持久状态的世界层资源分配 | 每个调度时标 |
| PiTurn | 从输入到稳定停止的一次模型—工具循环 | 一个 API token 或一次工具调用 |
| Harness | 提供会话、工具、进程与恢复边界的执行基质 | 科学主张的证据 |
| Worker | 运行时中的有界执行角色或进程 | 人类雇员 |
| Profile | 应用层能力上限 | 操作系统沙箱 |
| uncertain | 外部工作可能发生但无法确认 | 成功或失败的委婉说法 |
| cold build | 在干净目录中使用锁定依赖构建 | 复用旧输出的增量构建 |
| longitudinal causality | 长期反事实证据表明机制改变后续行为 | 代码存在或一次演示 |

## 数据权威

Pi JSONL 是完整模型—工具会话真源。SQLite 是世界状态、关系、授权、因果终态与
恢复真源。

## 版本写法

- 产品与 Web 版本：`0.2.0-alpha.1`
- Python 包版本：`0.2.0a1`

二者表示同一个发布候选。
